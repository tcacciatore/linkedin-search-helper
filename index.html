Remplissez les champs ci-dessous, puis cliquez sur "Lancer la recherche sur LinkedIn". Vous n'avez rien d'autre à faire : la recherche s'ouvrira directement dans LinkedIn avec tous les bons critères.

Séparez les différents intitulés possibles par des virgules. Exemple : Développeur, Ingénieur logiciel, Programmeur
Le candidat doit avoir TOUS ces mots dans son profil. Séparez-les par des virgules. Exemple : Python, SQL
Le candidat doit avoir AU MOINS UNE de ces compétences. Séparez-les par des virgules. Exemple : Docker, Kubernetes, AWS
Les profils contenant ces mots ne seront PAS proposés. Séparez-les par des virgules. Exemple : Stage, Alternance
Le candidat doit se trouver dans l'un de ces départements ou villes. Séparez-les par des virgules. Exemple : Paris, Hauts-de-Seine, Lyon
Le candidat travaille (ou a travaillé) dans l'une de ces entreprises. Séparez-les par des virgules. Exemple : L'Oréal, Danone
Le candidat travaille dans l'un de ces secteurs. Séparez-les par des virgules. Exemple : Luxe, Cosmétique
Cochez un ou plusieurs niveaux. Si vous ne cochez rien, tous les niveaux seront inclus.
